# Code of Conduct

## Our standard

Project Broadsheet is a small open-source project. Contributors are expected to engage professionally and in good faith. That means:

- Be direct and specific in issue reports and pull requests
- Critique ideas, not people
- Accept feedback graciously — everyone is here to improve the project
- Keep discussions on topic and constructive

## Scope

This standard applies in all project spaces: GitHub Issues, Discussions, Pull Requests, and any other venue where you are representing the project.

## Enforcement

Issues with contributor conduct can be reported to hello@projectbroadsheet.com. Reports are reviewed by the project maintainer and handled privately. Repeat or serious violations may result in a permanent ban from project spaces.

## Summary

Be professional. Be helpful. Be direct. That is all this project asks.
